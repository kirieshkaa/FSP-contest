🐄 API прогнозирования динамики стада КРС (numpy-версия)

Сервис строит помесячные прогнозы численности и продуктивности стада на основе CSV-файла с поголовьем. Реализованы три источника параметров, два режима закупки (фиксированный и автоматический подбор) и новый режим с целевым годовым ростом и кривой распределения закупок по месяцам.

POST http://127.0.0.1:8000/predict

📌 Параметры запроса (multipart/form-data)

ПараметрТипОбязательныйОписаниеЗначение по умолчанию
file file Да CSV-файл с данными о животных. Кодировка UTF-8, разделитель ; или ,. Должен содержать колонки: 'Номер животного', 'Дата рождения', 'Лактация', 'Дни в доении', 'Дни стельности', 'Дата архива', 'Статус коровы' и др. (см. пример ниже). —
months int Нет Количество месяцев прогноза. Игнорируется, если указана target_date. 36
purchase int Нет Фиксированное количество нетелей, закупаемых каждый месяц. Игнорируется, если maintain_replacement=True. 0
target_date str Нет Целевая дата в формате YYYY-MM-DD. Если указана, прогноз строится до этой даты (включительно), параметр months игнорируется. Возвращается интерполированный прогноз на эту дату. None
params_source str Нет Источник параметров модели:
custom – используются значения из параметров age_first_insem, prob_insem, …;
empirical – параметры вычисляются из загруженного файла;
constants – фиксированные константы (395 дней, 0.20, 282, 220, 0.025).		 custom
maintain_replacement bool Нет Включение автоматического подбора закупки. Если true, то:
  • При отсутствии growth_target выполняется старый бинарный поиск фиксированной ежемесячной закупки для сохранения численности.
  • При наличии growth_target активируется новый режим: подбирается годовой объём закупок, распределяемый по месяцам согласно кривой purchase_curve, чтобы достичь целевого годового темпа роста.
 false
growth_target float Нет Целевой годовой темп роста взрослого поголовья. Например, 0.1 означает +10% в год. Работает только при maintain_replacement=true. None
purchase_curve str Нет Кривая распределения годового объёма закупок по 12 месяцам. Принимает:
  • JSON-список из 12 чисел: "[1.2, 0.8, 1.0, ...]"
  • Строку из 12 чисел, разделённых запятыми: "1.2,0.8,1.0,…"
Числа нормируются автоматически, важны только пропорции. Если параметр не указан, используется равномерное распределение. 		None
Параметры для кастомного режима (params_source=custom)
age_first_insem int Нет Возраст первого осеменения (в днях). 395
prob_insem float Нет Вероятность успешного осеменения за месяц. 0.20
gestation int Нет Длительность стельности (дни). 282
dry_period int Нет День стельности, с которого корова переводится в сухостой. 220
culling_rate float Нет Базовая ежемесячная вероятность выбраковки/смерти. 0.025

📤 Ответ сервера

Возвращается JSON. Структура зависит от наличия target_date и режима подбора.

Без целевой даты (обычная история):

[
  {
    "month": "2026-03",
    "avg_dim": 145.2,
    "cows_count": 120,
    "total_adults": 185,
    "milk_total": 54000,
    "first_calvings": 3,
    "purchased": 2
  },
  ...
]

С целевой датой:

{
  "history": [ ... ],
  "target_forecast": {
    "month": "2027-09-01",
    "avg_dim": 158.4,
    "cows_count": 132,
    "total_adults": 198,
    "milk_total": 61200
  }
}

При использовании maintain_replacement=true (без роста):

{
  "history": [ ... ],
  "optimal_purchase_per_month": 5
}

⚙️ Логика работы нового режима (growth_target + кривая)

Если включены maintain_replacement=true и задан growth_target, прогноз разбивается на полные годы. Для каждого года выполняется:

  1. Вычисляется целевое взрослое поголовье на конец года: текущее * (1 + growth_target).
  2. Бинарным поиском подбирается общее количество нетелей, которое нужно закупить за год.
  3. Найденный годовой объём распределяется по месяцам пропорционально весам из purchase_curve (методом наибольшего остатка, чтобы получить целые числа).
  4. Проводится симуляция года с этими помесячными закупками.

Если прогноз короче года, кривая всё равно используется, но только для первых months месяцев. Подбор годового объёма для неполного года не производится (используется последняя найденная пропорция).

📁 Примеры входных данных (CSV)

Файл должен содержать как минимум следующие колонки (остальные игнорируются):

Номер животного;Дата рождения;Дата архива;Лактация;Дата начала тек.лакт;Дни в доении;Статус коровы;Дата осеменения;Дата успешного осеменения;Дни стельности;Дата запуска тек.лакт;Дата ожидаемого запуска;Дата ожидаемого отела

Даты в формате ДД.ММ.ГГГГ.

📁 Примеры запросов (cURL)

1. Фиксированная закупка 5 голов в месяц, кастомные параметры

curl -X POST http://127.0.0.1:8000/predict \
  -F "file=@herd.csv" \
  -F "months=24" \
  -F "purchase=5" \
  -F "params_source=custom" \
  -F "age_first_insem=400" \
  -F "prob_insem=0.25"

2. Автоподбор для сохранения численности (старый режим)

curl -X POST http://127.0.0.1:8000/predict \
  -F "file=@herd.csv" \
  -F "months=36" \
  -F "maintain_replacement=true"

3. Режим роста + кривая (JSON-список)

curl -X POST http://127.0.0.1:8000/predict \
  -F "file=@herd.csv" \
  -F "months=60" \
  -F "maintain_replacement=true" \
  -F "growth_target=0.1" \
  -F "purchase_curve=[1.5,1.2,1.0,0.8,0.6,0.6,0.8,1.0,1.2,1.3,1.4,1.5]"

4. То же, но кривая как строка через запятую

curl -X POST http://127.0.0.1:8000/predict \
  -F "file=@herd.csv" \
  -F "target_date=2028-01-01" \
  -F "maintain_replacement=true" \
  -F "growth_target=0.05" \
  -F "purchase_curve=1.5,1.2,1.0,0.8,0.6,0.6,0.8,1.0,1.2,1.3,1.4,1.5"

5. Эмпирические параметры из файла

curl -X POST http://127.0.0.1:8000/predict \
  -F "file=@herd.csv" \
  -F "months=48" \
  -F "params_source=empirical"

Версия API: 3.0 (numpy-core). Добавлены режимы роста и кривой закупок.
